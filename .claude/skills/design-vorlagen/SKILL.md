# Design-Vorlagen (awesome-design-md)

1. Pick the brand the user named (or suggest 2–3 fitting ones if they only describe a mood).
2. Brands are bundled alphabetically in `brands-a-f.md`, `brands-g-m.md`, `brands-n-s.md`, `brands-t-z.md` (this folder).
