# Kostenlose APIs (public-apis)

1. Grep `public-apis.md` (same folder) for the topic (search the `### <Category>` headings and keywords) — don't read the whole file.
2. Shortlist 2–4 candidates; prefer `Auth: No` or `apiKey`, `HTTPS: Yes`, `CORS: Yes` for browser use.
3. The list can be outdated: before recommending, check each candidate's current docs/pricing with web search or fetch, and say plainly if a service is dead or no longer free.
4. Give the user a short comparison plus a minimal working example call.
